# Example inputs

Place multi-type page images here for local smoke runs:

- plain text
- multi-column
- tables
- formulas
- figures with captions
- mixed Chinese / English
- complex reading order

Large OmniDocBench images are **not** committed. On the AMD evaluation host,
smoke samples live under `/root/workspace/samples` (copied from upstream Dolphin
demo pages / curated subset).

For CI-safe fixture images used by unit tests, see `tests/fixtures/`.
