No upstream Issues or PRs are published from this project without explicit
maintainer approval.

## Draft location

- Drafts: `evidence/upstream-issues/<target>-<short-name>.md`
- Attachments / minimal repros: `reproductions/<target>/<short-name>/`

## Quality bar

Only draft when all are true:

- reproduced ≥3 times
- minimal reproduction exists
- full environment captured
- expected vs actual documented
- raw logs retained
- component isolation attempted
- existing issues searched
- impact and workaround (or “none”) stated
- correct target repository identified
